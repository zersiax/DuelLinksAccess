# Superpowers artifacts

Superpowers specs are working design records. Once implementation and runtime verification settle a decision, rewrite it as a canonical document under `docs/design`.

Execution plans under `docs/superpowers/plans` are ignored. They contain temporary checklists, can become stale after implementation, and are not part of the public maintenance contract.

The automatic draw work began as a Superpowers spec. Its verified design is now tracked at [automatic draw](../design/automatic-draw.md).

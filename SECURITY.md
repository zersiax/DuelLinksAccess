# Security policy

## Supported versions

Security fixes target the latest published release and the current `main` branch.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature when it is available for this repository. Do not post credentials, account identifiers, private logs, or exploit details in a public issue.

For ordinary crashes or accessibility defects without sensitive data, open a normal GitHub issue. Remove personal information from MelonLoader logs before attaching them.

This mod runs inside the Duel Links process and loads local native libraries. Download MelonLoader and Tolk only from the upstream projects linked by this repository. Verify published hashes before installing native files.

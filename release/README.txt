DuelLinksAccess installation
============================

Requirements
------------

- Yu-Gi-Oh! Duel Links for Steam on 64-bit Windows
- MelonLoader 0.7.3 or later, installed for dlpc.exe
- NVDA running before the game starts
- Tolk from the verified archive listed in THIRD_PARTY_NOTICES.md

Install
-------

1. Install MelonLoader and launch Duel Links once.
2. Download Tolk from the URL in THIRD_PARTY_NOTICES.md.
3. Verify the Tolk ZIP SHA-256 before extracting it.
4. Put Tolk.dll and nvdaControllerClient64.dll beside dlpc.exe.
5. Copy Mods\DuelLinksAccess.dll from this archive into the game's Mods folder.
6. Start NVDA, then start Duel Links.

Press F1 in the game to hear the current controls.

This package does not include Tolk, screen reader client libraries, MelonLoader,
or game files. Troubleshooting and current controls:
https://github.com/zersiax/DuelLinksAccess
